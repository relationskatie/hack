# ЦОДД Смоленской области - Веб-платформа

Современная веб-платформа для Центра организации дорожного движения Смоленской области, разработанная для хакатона. Платформа предоставляет информационные услуги для граждан и административные инструменты для сотрудников ЦОДД.

## 🚀 Технологический стек

- **Frontend Framework:** Next.js 15 (App Router)
- **UI Libraries:** Material-UI (MUI) v7 + Tailwind CSS v4
- **Язык:** TypeScript 5
- **Графики:** Recharts + MUI X Charts
- **Карты:** Leaflet + React-Leaflet
- **Управление состоянием:** Context API + Zustand
- **Стилизация:** Emotion + Tailwind CSS
- **Формы:** React Hook Form + Zod
- **HTTP клиент:** Axios + Fetch API
- **Шрифты:** Golos Text (основной), Comfortaa (заголовки)

## 📋 Основные функции

### Для граждан:
- 🏠 Информационный портал о деятельности ЦОДД
- 📊 Публичная статистика дорожного движения с визуализацией
- 🚗 Онлайн-заявка на вызов эвакуатора
- 📰 Новости и проекты организации
- 📞 Контактная информация и услуги

### Для сотрудников:
- 🔐 Система авторизации с ролевой моделью (админ/редактор)
- 📝 Панель управления контентом
- 📈 Расширенная аналитика (только для администраторов)
- 🚦 Управление данными о светофорах и инфраструктуре

## 🛠 Установка и запуск

### Требования:
- Node.js 18+
- npm или yarn

### Установка:

```bash
# Клонирование репозитория
git clone [repository-url]
cd smolensk-tsodd

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшена:

```bash
# Создание оптимизированной сборки
npm run build

# Запуск продакшен сервера
npm start
```

9. **Карта инфраструктуры** (`/infrastructure-map`) - интерактивная карта светофоров и камер
