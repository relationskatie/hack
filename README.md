# Цифровая веб-платформа для Центра организации дорожного движения Смоленской области
# https://smolensk-tsodd.vercel.app/

## Роли пользователей
Платформа поддерживает **четыре роли пользователей**:

- **unknown** — базовый пользователь, может только просматривать страницы
- **user** — может заказывать услуги через платформу
- **editor** — управляет контентом, например, новостями и документами
- **admin** — полный доступ к управлению сайтом через админскую панель

## Архитектура
Для реализации платформы была выбрана **микросервисная архитектура** с использованием двух языков программирования: **Go** и **Python**. Go отвечает за многопоточность и обработку highload-нагрузки, Python используется для детального анализа данных с применением методов машинного обучения.

### Api-Gateway (Go)
Служит точкой входа для всех запросов к четырём микросервисам и работает по протоколу HTTP. Встроена валидация ролей, что позволяет реализовать систему авторизации, контролировать доступ пользователей и гибко добавлять новые роли в будущем.

### OrderService и LocationService (Go)
- **OrderService** управляет услугами с возможностью их заказа, включая услуги с расписанием и без. Для администраторов доступен просмотр заказов и изменение их статуса.
- **LocationService** предоставляет информацию о светофорах, включая тип и дату установки.

### AnalyticService и ContentService (Python)
- **ContentService** реализует CRUD для различных данных сайта: контактов, документов, новостей и вакансий. Для некоторых типов данных (например, контактов) использовались связанные таблицы для хранения структурированной информации.
- **AnalyticService** предоставляет модульные методы работы с аналитикой: загрузка собственных файлов с режимами **append** и **replace**, получение метрик, сравнение между периодами и предсказание значений на будущее.

## База данных
Для всех сервисов использовалась **PostgreSQL** с драйвером **pgx**, что обеспечило надёжную работу с транзакциями, масштабируемость и высокую производительность.

## Хранение файлов
Хранение файлов организовано через **MinIO** (совместимо с Amazon S3 API), что позволило безопасно и удобно работать с документами и медиафайлами без сторонних облачных сервисов.

## Используемые технологии и подходы
- **SQLAlchemy** — ORM для удобного взаимодействия с базой данных на Python
- **gRPC** — высокопроизводительный протокол для коммуникации между микросервисами
- **python-magic** — проверка типов загружаемых файлов для безопасности системы
- **Pydantic** — валидация данных и работа с типами, повышающая надёжность сервиса

В результате получилась **масштабируемая, надёжная и высокопроизводительная платформа**, обеспечивающая социально-ориентированное взаимодействие с гражданами, формирование единой базы данных и возможность интеграции умной аналитики.
